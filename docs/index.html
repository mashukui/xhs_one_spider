👋 软件简介 👋 Overview

xhs_one_spider 是一款面向小红书内容数据采集场景的桌面 GUI 工具。 支持关键词搜索笔记采集、指定笔记评论采集、博主主页笔记采集、笔记图片批量下载， 以及小红书链接与用户 UID 互转等功能，所有数据均可导出为 CSV 文件。 用户无需配置 Python 环境，下载客户端后登录即可使用。

xhs_one_spider is a desktop GUI tool for Xiaohongshu (RED) data collection. Supports keyword-based note crawling, comment scraping, blogger profile posts, image batch downloading, and URL-to-UID conversion — all exported as CSV. No Python setup required — just download and run.

❓ 常见问题 ❓ FAQ

🟢 是否需要安装 Python？
不需要。软件已打包为桌面客户端，下载对应系统版本后即可运行。
🟢 Do I need to install Python?
No. The software is packaged as a standalone desktop app — just download and run.
🟢 Cookie 如何配置？
软件内置 Cookie 小工具，打开后按提示扫码或粘贴即可自动获取小红书登录凭证，无需手动抓包。
🟢 How do I set up the Cookie?
The software includes a built-in Cookie Tool — simply scan the QR code or paste as prompted to automatically obtain your Xiaohongshu login session. No manual packet capture needed.
🟢 采集中断后数据会丢失吗？
不会。软件在采集过程中持续保存结果，网络异常或任务中断不会丢失已采集的数据。
🟢 Will I lose data if crawling is interrupted?
No. Results are saved continuously — network issues or interruptions won't wipe collected data.
🟢 支持导出哪些格式？
支持导出 CSV 格式（UTF-8 编码），可直接使用 Excel / WPS / Numbers 打开，也方便导入数据库或进行二次分析。
🟢 What export formats are supported?
CSV format (UTF-8 encoding). Open directly in Excel / WPS / Numbers, or import into databases for further analysis.

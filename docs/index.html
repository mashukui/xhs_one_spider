核心功能

围绕小红书公开内容整理流程设计：先按关键词找笔记，再整理评论、博主主页和图片素材。

关键词

搜索笔记采集

按关键词搜索小红书笔记，整理标题、正文、作者、发布时间和互动数据。

评论

评论采集

采集指定笔记或搜索结果笔记下的评论内容、评论者和互动信息。

博主

主页笔记采集

输入博主主页链接，批量整理公开笔记列表，并可按需下载图片文件。

转换

链接与 UID 转换

支持主页链接、小红书号、UID、笔记链接之间的常见格式转换。

适合哪些使用场景

常见问题

这里回答购买前最常见的问题。更细的字段说明、图片下载说明和反馈格式请查看 GitHub README。

是否需要安装 Python？

不需要。软件已经打包为桌面客户端，下载对应系统版本后即可运行。

Cookie 是做什么用的？

Cookie 用于让软件以当前账号状态访问平台公开数据。请使用自己的小红书账号 Cookie。

图片下载失败怎么办？

请检查网络环境、图片链接是否有效、输出目录是否可写，以及当前账号是否具备访问该笔记的权限。

采集中断后数据会丢失吗？

软件会在采集过程中持续保存结果，已完成部分通常会保留在 CSV 文件中。

准备整理小红书公开数据？

先看演示或下载最新版，也可以直接进入商品页开通授权。
